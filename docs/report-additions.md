## Cross-case comparison table
| Case study | Model | Scaling achieved (p = 2) | Dominant bottleneck |
|---|---|---|---|
| Heat diffusion | MPI | S = 2.01, E = 1.00 | memory bandwidth, then halo sync |
| k-mer counting | OpenMP | S = 1.93, E = 0.96 (k = 8, private) | atomics / false sharing; latency at k = 12 |
| Monte Carlo | OpenMP (+MPI) | S = 1.98, E = 0.99 | none (serial fraction 1.1 %) |
| PageRank | OpenMP | S = 2.12 (dynamic,1024); 1.45 static | load imbalance, random-access latency |
| Sample sort | MPI | S = 1.77, E = 0.88 | extra O(N) exchange and merge |
